## Follow-ups

- [x] F.1 Mixed Hebrew and Latin text in the playback sheet subtitle rendered in the wrong order (seen on an iPhone for a playlist named in Hebrew). Cause: React Native Web gives every `Text` `dir="auto"`, which takes the direction of the first strong character, so a line like `<name> · 1 of 2` became a right-to-left paragraph, right-aligned with the position left of the name. Fix: `isolateBidi` (utils/bidi-isolate.ts) wraps a right-to-left name in a first-strong isolate where the app joins one into a line (playback labels, mini-player context, playlist detail line, folder path in Files rows, recording picker and Drive status titles), and `LEFT_TO_RIGHT_LINE_STYLE` sets the direction on the three lines that show them. Plain names are unchanged. Unit specs for both and browser scenario `rtl-names` (failed before)
- [ ] F.2 Check the order of a Hebrew name that ends in digits (`אור-פנד-לנד-2026-12-09`) on iOS Safari. Chromium shows the isolated, right-to-left order (digits at the left, `2026-12-09-לנד-פנד-אור`); the iPhone screenshot after #52 shows the Hebrew words first and the digits at the right, as if the isolate is not applied by WebKit or something strips it.
